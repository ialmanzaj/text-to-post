# Project Brief

## Project Name
Text-to-Post Generator

## Core Requirements
- Allow users to input, format, and preview text content for social media posts.
- Enable export of formatted content as images in various aspect ratios and resolutions suitable for different platforms.
- Provide a user-friendly interface for editing, previewing, and exporting content.

## Goals
- Streamline the process of turning text into visually appealing social media images.
- Support multiple export sizes for different social media platforms.
- Ensure high usability and accessibility for a broad range of users.

## Scope
- Web-based application (React/TypeScript).
- No backend required for core functionality (client-side export).
- Focus on extensibility for future features (themes, templates, etc.).
