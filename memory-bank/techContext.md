# Tech Context

## Technologies Used
- React (with TypeScript) for UI and logic
- Tailwind CSS for styling
- html2canvas for DOM-to-image export
- Lucide React for icons

## Development Setup
- Node.js and npm/yarn for package management
- Vite or Create React App as the build tool (assumed, update if different)
- All code in `src/` directory, with components in `src/components/`

## Technical Constraints
- All core features must work client-side (no backend dependency)
- Exported images must be high-resolution and suitable for social media
- App must be responsive and accessible

## Dependencies
- react
- react-dom
- typescript
- tailwindcss
- html2canvas
- lucide-react
