# Product Context

## Why This Project Exists
Social media creators and marketers often need to turn text content into visually engaging images for platforms like Instagram, LinkedIn, and Twitter. Existing tools are either too complex, lack flexibility, or do not support easy formatting and export for multiple aspect ratios.

## Problems It Solves
- Manual design of text posts is time-consuming and inconsistent.
- Lack of easy, repeatable workflows for turning text into images.
- Difficulty in previewing and exporting content for different social media requirements.

## How It Should Work
- Users paste or type their content, optionally using section titles and bullet points.
- The app parses and formats the content into a visually appealing layout.
- Users can preview the result in a mobile frame and export it as an image in various sizes.

## User Experience Goals
- Fast, frictionless workflow from text to image.
- Intuitive, minimal interface with clear feedback.
- Support for common social media post sizes and easy export.
